References and credits

Everything on this site that comes from outside our team, and where to find it.

Data

  • Brisbane City Council. Park – Locations [open dataset]. Brisbane City Council Open Data. data.brisbane.qld.gov.au/explore/dataset/park-locations. Used live to calculate the Parks & Recreation score. Check the licence shown on the dataset page and add the licence name here.
  • Opendatasoft. Explore API v2.1 (how the Council serves its data). data.brisbane.qld.gov.au/api-console/explore/v2.1.
  • Affordability, transport and safety scores are placeholder sample values written by our team. Rental listings and addresses are made up.

Code and libraries

  • Leaflet 1.9.4, an open-source JavaScript map library, loaded from cdnjs. leafletjs.com · cdnjs.com/libraries/leaflet. Used on the "Browse suburbs" page (js/results.js).
  • MDN Web Docs. HTML Drag and Drop API, the pattern used to reorder priorities in the quiz (js/quiz.js). developer.mozilla.org.
  • Haversine formula for straight-line distances (js/app.js).

Map tiles

  • Map data © OpenStreetMap contributors, available under the Open Database Licence.

Font

Images and icons

  • Icons on this site are simple inline SVG drawings made for this project. The emoji next to each factor (💲 🚌 🛡️ 🌳) come from the visitor's device.
