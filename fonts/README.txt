Put the Open Sauce One font files here.

1. Download the font from https://www.1001fonts.com/open-sauce-font.html
2. Unzip it and copy these files into this folder (names must match exactly):
     OpenSauceOne-Regular.ttf
     OpenSauceOne-Medium.ttf
     OpenSauceOne-SemiBold.ttf
     OpenSauceOne-Bold.ttf
     OpenSauceOne-ExtraBold.ttf
3. If your files are named differently, either rename them or edit the
   @font-face rules at the top of css/theme.css.
4. Copy the licence text from the download into this folder too, and note the
   licence name on references.html.

Until the files are here, the site uses your device's default font, so nothing breaks.
